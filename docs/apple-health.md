# Apple Health ingestion
`health.<domain>` serves the InfluxDB 2.x UI and authenticated write API. Use the domain from [clusters/cloudlab/settings.yaml](../clusters/cloudlab/settings.yaml). iOS Apple Health access runs on the phone, never on the Linux host. Use an iOS export app capable of InfluxDB v2 line protocol, or convert Apple's exported XML locally and write line protocol. Configure organization `cloudlab`, bucket `apple-health`, URL `https://health.<domain>`, and a NEW bucket-write-only token from 1Password; never put the operator token on the phone. Configure the Access service token/header support before exposing this endpoint. If your exporter cannot send Access headers, use a private VPN/SSH ingestion path rather than weakening UI access.

Keep raw Apple XML on private local storage and import with an audited converter (not supplied). Verify timezone, measurement names, units, duplicate timestamps and health-data privacy. First test one measurement via `/api/v2/write?org=cloudlab&bucket=apple-health&precision=ns`, then chart it in Grafana with a separate bucket-read-only token stored as a SOPS Secret when provisioning the datasource. No unverified third-party exporter or invented package is installed here.
